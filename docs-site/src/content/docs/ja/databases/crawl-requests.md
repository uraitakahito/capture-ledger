**クロールを始める要求の鍵が 1 行です。** `POST /api/crawls` が、最初に始めたクロールの答えを組織と鍵の組ごとに覚えます。同じ鍵の送り直しには同じ答えを返し、2 本目を始めません。動きは[同じ要求を 2 回送っても 1 本](/capture-ledger/ja/archive-ledger/#同じ要求を-2-回送っても-1-本)に書きました。


| 列               | 中身                                                                  |
| ---------------- | --------------------------------------------------------------------- |
| `org_id`・`key`  | 主キー。組織は呼び出し元の 1 つ目の組織。別の組織の同じ字は混ざらない |
| `request_sha256` | 本文の digest（鍵を並べ替えた JSON の sha256）。違えば 422            |
| `crawl_id`       | 始めたクロール。行を消すと鍵も消える                                  |
| `answer`         | 返した 202 の本文（`{ "crawlId": … }`）                               |
| `created_at`     | 鍵の期限（24 時間）の起点                                             |

## 覚えるのは始めた答えだけ

走行中の 409 と中身の 400 は覚えません。覚えると、走っている 1 本が終わった後や本文を直した後に、同じ鍵で送り直しても始まらなくなります。

## 消し方

24 時間より古い行は、次に始める要求が消します（`created_at` の index）。定期実行の回は API を通らないので、この表に行を作りません。
